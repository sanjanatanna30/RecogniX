# RecogniX – Smart Attendance Management System

## Project Overview

**RecogniX** is a smart attendance management system that uses **face recognition technology** to automate and simplify the student attendance process. The system integrates a web-based interface with a backend server, database, and Python-based face recognition module to identify students and manage attendance records efficiently.

The goal of this project is to provide a **faster, more accurate, and user-friendly attendance solution** while reducing the effort required for manual attendance management.
